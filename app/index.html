Instaliraj WEB VIJESTI kao aplikaciju

Stranicu možeš koristiti kao web aplikaciju na mobitelu, tabletu i desktop računalu. Ne trebaš skidati klasični instalacijski program; aplikacija se instalira iz preglednika.

Važno: ovo je PWA / web aplikacija. Sadržaj ostaje na GitHub Pages hostingu, a na uređaju dobivaš ikonu i otvaranje kao aplikacija. Kada spojiš vlastitu domenu, iste upute vrijede i za novu domenu.
Android · Chrome

Mobitel Android

  1. Otvori Chrome na mobitelu.
  2. Otvori adresu portala:
    aktualmedia.github.io/all-business-news
  3. Dodirni izbornik s tri točkice u gornjem desnom kutu.
  4. Odaberi Dodaj na početni zaslon ili Instaliraj aplikaciju.
  5. Potvrdi naziv WEB VIJESTI.
  6. Na početnom zaslonu pojavit će se ikona portala.
iPhone · Safari

iPhone / iPad

  1. Otvori Safari.
  2. Otvori adresu portala.
  3. Dodirni ikonu Share / Dijeli.
  4. Odaberi Add to Home Screen / Dodaj na početni zaslon.
  5. Potvrdi naziv aplikacije.
  6. Pokreći ćeš portal iz ikone kao aplikaciju.
Desktop · Chrome / Edge

Desktop računalo

  1. Otvori portal u Chromeu ili Microsoft Edgeu.
  2. U adresnoj traci potraži ikonu instalacije ili otvori izbornik s tri točkice.
  3. Odaberi Install WEB VIJESTI ili Apps → Install this site as an app.
  4. Potvrdi instalaciju.
  5. Aplikacija će se otvoriti u zasebnom prozoru i možeš je pinati na taskbar.
Najbrži pristup: za mobilni rad koristi ikonu aplikacije, a za uređivanje i provjeru koristi rubrike ADMIN, STATUS, VIDEO, SYMBOL i RADIO.
